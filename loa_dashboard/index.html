Needs More Info — Root Cause Analysis 1,383 queries · 18.7%
💡 Why Queries Land Here
43% are single-word or vague responses (e.g. "yes", "mine", "medical") — users answering a follow-up prompt from SAGE with insufficient detail. 16% are general "Learn More About LOA" inquiries where SAGE needs the user to specify a leave type before proceeding. 10% describe medical or injury situations without enough context (e.g. "I broke my leg", "surgery") to determine leave type and eligibility. These patterns suggest users need clearer prompting at the point of input to provide structured leave type selection upfront.
